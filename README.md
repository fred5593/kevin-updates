# KEVIN Updates

Canale pubblico ufficiale per la distribuzione degli aggiornamenti Android di KEVIN.

- `latest.json` indica all'app la release più recente.
- Gli APK vengono pubblicati come GitHub Release assets.
- Il codice sorgente dell'app resta nel repository privato `kevin-android`.
- KEVIN verifica package, versione e SHA-256 prima dell'installazione.
